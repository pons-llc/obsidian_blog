このブログには Claude Code のスキルが2つ組み込まれている。[[ObsidianとFlask-Frozenでブログを作った理由|ブログ全体の構成]]はこちら。

スキルとは、よく使う作業手順を Claude Code に覚えさせたもの。プロジェクトルートで Claude Code を開いてスキル名を呼ぶと、そのワークフローに沿って作業を進めてくれる。

## `/blog` — 投稿を会話で作る

```
/blog 新しい記事を書きたい
```

と呼ぶと、タイトルを確認してフロントマター付きの Markdown ファイルを自動で作ってくれる。スラッグの生成、今日の日付の入力、テンプレートの適用——これらをすべてやってくれるので、自分はすぐ本文を書き始められる。

```
/blog ビルドして
/blog 下書き一覧を見せて
```

のように、ビルドや投稿管理の作業も任せられる。

## `/design` — デザインを会話で決める

```
/design
```

と呼ぶと、ブログの用途・雰囲気・カラー・フォントについて聞いてくれる。答えるだけで `style.css` を書き換えてくれて、プレビューサーバーを立ち上げて確認できる。

「もっと余白を増やして」「アクセントカラーをオレンジにして」と追加で伝えると、その場で修正してくれる。CSSを手で書かなくていい。

## スキルはプロジェクトに同梱されている

スキルのファイルは `.claude/skills/` に入っている。つまりリポジトリを clone した人全員が同じスキルを使える。チームでブログを運営するときも、全員が同じ操作体験で作業できる。
